# Montage

A professional non-linear video editor written in **C++20** with **Qt 6** and **FFmpeg**.

Montage follows the same technology choices as the editors it is modelled on. Adobe Premiere Pro,
DaVinci Resolve, Avid Media Composer, Lightworks and Vegas Pro are written in C++, and the open-source
professional editors (Kdenlive, Shotcut, Olive) use C++ with Qt for the interface and FFmpeg for media.
Final Cut Pro is the exception: it is written in Objective-C/Swift on Apple-only frameworks.

## Features

**Editing**
- Multi-track timeline: unlimited video and audio tracks, with lock, sync-lock, mute, solo, hide and track targeting
- Tools: Selection (V), Razor (C), Ripple (B), Roll (N), Slip (Y), Slide (U), Hand (H)
- **Trim mode** (Avid's and Premiere's keyboard trimming): `Shift+T` selects the edit nearest the playhead on the target video track, `Alt+T` switches between both sides (a roll), the outgoing side and the incoming side (ripple trims), and `Ctrl+Left`/`Ctrl+Right` trim a frame at a time (five with `Shift`). Red brackets mark the sides being trimmed, the playhead and the two-up view follow the edit, each trim is one undo step, and `Esc` ends it.
- **Two-up trim view** (as in Premiere, Resolve, Avid and Final Cut): while an edit is trimmed, rolled, slipped or slid, the Program monitor shows the frames either side of it side by side, each labelled with its clip and timecode (a slip shows the clip's first and last frames). Playback › Two-Up Trim View turns it off.
- Insert, overwrite, lift, extract, ripple delete, close gap, nudge, duplicate, copy / paste / paste-insert. **Gaps** (Premiere's, Resolve's): click the empty stretch between two clips to select it and press Delete to close it, rippling what follows. As in Resolve 21.1, a selected gap can also be copied or cut (closing it) and pasted at the playhead as that much empty space, splitting a clip there and pushing what follows on sync-locked tracks.
- **Transition handles** (Premiere 26's): drag either edge of a dissolve on the timeline, or a fade's edge away from the cut, to make it longer or shorter, with its length shown as you drag. A dissolve stays centred on the cut and inside both clips; one undo step.
- Three-point editing from the Source monitor (I / O marks, `,` insert, `.` overwrite, drag from the viewer)
- **Reverse Match Frame** (Premiere's, `Shift+R`; Clip menu): the frame showing in the Source monitor, found in the sequence: the playhead goes to it and its clip is selected. Pressed again it steps to the next place that frame is used (any track, at any speed or reversed), round to the first. Match Frame (`F`) goes the other way, through nested sequences and multicam clips (their angle) to the file underneath, as Resolve 21's does.
- **Compare with Sequence** (Resolve 21.1's timeline comparison; Sequence menu): duplicate a sequence before a round of changes, then compare the two versions. A list shows each clip added, removed, trimmed (its in and out points in source frames), moved (to another track, or changed places with its neighbours) or changed (speed, effects, picture, sound, a title's text); clips that only slid along with the edits around them are left out, and a clip's linked sound is not listed twice. Double-click to go to a change; **Add as Markers** puts a coloured marker on the sequence for each one (one undo step). MCP `montage_compare_sequences`.
- **Change lists and re-conform** (Avid's Change List tool, the Conformalizer; Compare with Sequence › Change List): the new cut's picture matched frame by frame to the old one's, as events: stretches kept in their old order (and how far they slid), moved, inserted, extended, deleted and trimmed. **Export Change List** writes a change EDL (CMX 3600, the old cut as reel OLDCUT and new material as NEWCUT, for Pro Tools and VFX conform tools) or a CSV. **Re-conform** rebuilds a sequence cut to the old version (the sound mix, the grade, effects and titles over it) to play against the new one: every track's clips, transitions and fades, track and bus automation, markers and captions carried to where the new cut plays them, new material filled in from the new cut (labelled), markers on what was added and taken out; one undo step. MCP `montage_reconform`.
- **Selection readout** (Resolve 21): the status bar shows how many clips are selected and how long they run, first start to last end.
- The Cut page's other source edits (Clip menu): **Append at End** (Shift+F12), **Place on Top** (F12: the first tracks above the target with room, new ones if none, nothing below moves), **Ripple Overwrite** (Shift+F10: the clip under the playhead becomes the source range and everything after moves by the difference) and **Smart Insert** (insert at the edit nearest the playhead, so a cut never lands mid-clip). The MCP `montage_place_media` tool takes the same as `mode`.
- **Source monitor waveform** (as Premiere 26.2 shows): a clip with sound shows its audio waveform on the Source monitor's scrub bar, so a line or a beat can be marked by eye
- **Record Voiceover** (Sequence menu, Ctrl+Alt+R): record from any audio input onto an audio track where the playhead is, with a level meter and a 3-second countdown, while the picture plays along. Punch In records from In to Out and stops by itself. Each take is saved as a WAV in a Voiceover folder beside the project, filed in the media bin and placed on the track as one undo step.
- **ADR (dialogue replacement)** (Pro Tools' and Fairlight's ADR tools; Premiere, Final Cut and Media Composer have none; Sequence › ADR, a panel beside the Program monitor): a cue list kept with the sequence (cue number from the character's initials, character, line, a note on why, start, end, status: To Record, Recorded, Approved, Omitted), made from captions (a speaker label like "ANNA:" or "[Anna]" is the character), range markers, In to Out, or a cue sheet (CSV or tab separated, Pro Tools-style column names, timelines from 01:00:00:00 understood), and written back out as a cue sheet. **Rehearse** plays a cue's cycle: pre-roll, three 1 kHz beeps a second apart with the line where the fourth would be, a white streamer crossing the picture to the line, a punch on its first frame and the line itself over the picture. **Record** plays it again and records the actor (the guide track muted if wished, and the takes already made), each take landing as a take of one audition clip over the line on an ADR track (overlapping lines on ADR 2, 3...), in sync, the newest the pick, a take stopped before the line not kept; **Loop** records take after take until stopped. Takes are picked from the panel or like any audition. MCP `montage_adr` (list, add, from captions or markers, update, cue sheets, add and pick takes); re-conforming a sequence to a new cut carries its cues along.
- **Audio description** (described video, as broadcasters and streaming services ask for; no other editor has tools for it; Sequence › Audio Description): finds the gaps between the dialogue (speech on the audio tracks, kept clear of the lines), lists them with the descriptions written into each and whether each fits at a describer's pace (how many words to cut if not), voices them with the AI voices onto an AD track as clips of the role Description (a little faster where a gap is short), ducks the programme under them, and mutes them while working if wished. Export's audio description option writes the mix without the descriptions and a second stream, "Audio Description", of the programme with them. MCP `montage_audio_description` (gaps, write, list, voice, duck, hear) and `montage_render` `described`.
- **Track folders** (Resolve 21's Fairlight folders): right-click a track header › Folder to put tracks in a new or existing folder. A folder's header collapses its tracks (their clips shown in outline on its row), and its M and S (or ◉ for video) buttons mute, solo or hide all of them; member tracks carry an amber stripe. Rename or remove a folder from its header's menu. An audio folder also gets a **VCA fader** in the Audio Mixer (as in Fairlight and Pro Tools): its level is added to each of its tracks' faders in the mix and in exports, so a group of dialogue tracks can be ridden together. Saved with the sequence.
- **Out-of-sync indicators** (Premiere's red sync numbers, Avid's sync breaks): a linked clip that has slipped out of step with its picture (moved or slipped on its own, same media at the same speed) shows the frames it is late (+) or early (-) in a red box on its name strip; right-click for Move into Sync (moves it back) or Slip into Sync (slips its source in place, refused past the media's ends). Quality Check lists out-of-sync clips; MCP `montage_sync` (check, move, slip) and `montage_quality_check` `sync`.
- **Through edits** (Premiere's through edit indicators): a cut the picture or sound runs straight through (what a razor cut leaves: the same media continuing at the same speed with no transition) gets a small white arrowhead, and Clip › Join Through Edits puts the selected clips (or the whole sequence) back together with their linked sound, as one undo step.
- **Clip durations** (Resolve 21.1's view option; Sequence › Show Clip Durations): each clip's length as timecode in its name strip, where the clip is wide enough.
- **Normalise Waveforms** (Resolve 21.1's independent waveform scaling; Sequence menu): each audio clip's waveform drawn to the full height from its own loudest point, so quiet dialogue and room tone are readable; the clip's level no longer scales the drawing.
- **Duplicate frame markers** (Premiere's; Sequence › Show Duplicate Frame Markers): video frames used more than once in the sequence get a stripe along the bottom of each clip that repeats them, one colour per file, so a reused shot is caught before delivery. Speed changes are followed; sound and titles are not counted.
- **Close Up** (Resolve's Cut page; Clip › Close Up): a punched-in copy (150 %) of the video clip under the playhead, over In to Out or the whole clip, goes on the track above, framed on the face found in it (YuNet, with the People model installed) or else on the middle, without uncovering the frame's edges.
- **Layouts** (CapCut's layouts, Resolve's Video Collage; Clip › Layout): the selected video clips, or every video clip under the playhead, share the frame. **Side by Side**, **Top and Bottom**, **Three Across** and the **2 × 2 Grid** fill each cell (cropped from the middle, the lowest track first); **Picture in Picture** keeps the lowest clip full frame and puts the others, whole, in the corners at 30 % of the width; **Full Frame** puts them back. One undo step, ordinary scale, position and crop you can then adjust or animate. MCP `montage_layout` adds a gap between cells, the corner and the inset's size.
- **Auditions** (Final Cut's auditions, Resolve's take selector; Clip › Audition): select a clip and the alternative takes in the Media bin (or one in the Source monitor from its In) and choose Add Selected Media as Takes (Ctrl+Alt+Y). Ctrl+Alt+Right and Left then try each take in the clip's place, keeping its length, effects and keyframes, with linked sound following; the clip shows "take 2/3". Trims and splits carry the takes along. Finalize Audition keeps the pick. Saved with the project; Project Manager keeps every take's media. MCP `montage_audition`.
- Ripple Trim Previous / Next Edit to Playhead (Q / W), Select Clips After Playhead (A, Shift+A on the target track), Replace with Source Clip, Fit to Fill, Add Frame Hold (Shift+F; Time Remapping can also go to 0 % to hold mid-ramp), and Swap with Previous / Next Clip (Ctrl+Shift+, and Ctrl+Shift+.; like Resolve's swap and Final Cut 12.3's reorder: a clip and its neighbour change places with their linked sound, and a dissolve between them moves to the new edit; MCP `montage_swap_clip`)
- **Extend Clip** (a local counterpart to Premiere's Generative Extend): Clip › Extend Clip › By 1 Second, By 2 Seconds or To the Playhead carries a shot on past the end of its media. The last frame is held while the camera's motion over the shot's final half second (a pan, a drift, a push or a turn, measured by tracking its texture) carries on and eases to rest, scaled up just enough as it drifts that the frame stays filled, and its linked sound gets the room's own tone; what follows is pushed along, all in one undo step. MCP `montage_extend_clip`.
- **Delete Gaps** (Resolve's Edit › Delete Gaps): Edit › Delete Gaps closes every stretch of the timeline where no track has anything, so nothing slips out of sync (a picture gap over continuing sound stays); what follows moves up with its captions, markers, In/Out and track automation, in one undo step. Gaps a locked track's clips would have to cross stay. MCP `montage_delete_gaps` (optionally the empty start too).
- Paste Attributes (Ctrl+Alt+V) and Remove Attributes: motion, opacity and blend, Time Remapping, volume and effects, keyframes included
- Synchronise clips from separate cameras and recorders by audio waveform (cross-correlation, sub-frame accurate)
- Linked audio/video, linking and unlinking, snapping, markers, match frame, compound (nested) clips
- **Timeline tabs** (Premiere's and Resolve's): each sequence opened (from the bin, or made new) gets a tab above the timeline; click to switch, drag to reorder, close to put away (the last one stays open). Tabs follow renames.
- **Marker lists** (Sequence › Export / Import Markers, MCP `montage_export_markers` and `montage_import_markers`): export the sequence's markers as a CSV with Premiere's columns, as Avid Media Composer locators, as a marker EDL that DaVinci Resolve imports, or as a PDF with a picture of each marker's frame (Resolve 21.1's) for a review or a client; import notes from a CSV (review tools' Timecode/Comment exports work) or Avid locators, as one undo step. Lists made on timelines that start at 01:00:00:00 are moved to the start.
- **Clip markers** (Sequence › Add Clip Marker, `Shift+Alt+M`; Premiere's and Final Cut's): a marker on the selected clip at the playhead, kept on that moment of its media, so it travels with the clip through moves, trims, speed changes and splits. Drawn as flags on the clip, listed in the Sequence Index (renamable), saved, and carried by OpenTimelineIO (on the clip) and FCPXML (inside the clip; chapter markers as `chapter-marker`). MCP `montage_add_marker` with `clip`.
- **Changed media reload by themselves** (as Premiere and Resolve do): a still re-saved in Photoshop or a graphic re-rendered is picked up while you work: its cached frames, thumbnail and sound are dropped, its size and length re-read, and the monitors redrawn. **Edit Original** in the bin's context menu opens a file in its own application.
- **Interpret Footage** (Premiere's Interpret Footage, Resolve's Clip Attributes, Final Cut's Conform Speed and anamorphic override; right-click videos or stills in the media bin, or MCP `montage_interpret_media`): how a file is read, for every clip made from it. **Frame rate**: each of the file's frames shown for 1/rate of a second, so 120 fps footage assumed at 24 plays five times slower as smooth slow motion and 25 fps material conforms to 23.976; its sound conforms with it, at the new speed (varispeed) or with **Keep the audio's pitch** time-stretched to the new length. **Pixel aspect ratio**: the file's replaced (square, the D1/DV and HDV ratios, anamorphic 1.33x, 1.5x, 1.65x, 1.8x and 2x, or any value), so an unflagged anamorphic shot is shown desqueezed. **Alpha**: straight, premultiplied, ignored or inverted. **Field order**: progressive, upper or lower first whatever the frames are flagged, to deinterlace footage marked progressive or leave alone footage that is not interlaced. Clips keep starting on the same frame and keep their length on the timeline; subclips, clip markers, transcripts and the shot and face indexes keep to the same frames; one undo step. The interpretation travels with the media, so thumbnails, waveforms, proxies, analysis, exports, relinking and Project Manager copies all read it the same way.
- **Offline media and Link Media** (Premiere's Link Media and Replace Footage, Resolve's Relink, Final Cut's Relink Files): media whose files have moved show as **Media Offline**, a red slate in the monitors and red clips and tiles, and opening such a project brings up **Link Media**. Locate one file and the others are looked for beside it, or search a folder (and the folders inside it) for all of them; a file must be the same footage (kind, picture size, length) and a transcode is found by its name with another extension (A001.mxf as A001.mov). Each relink is one undo step and keeps the item's logging, transcript and clips. **Replace Footage** (the bin's context menu) swaps in a different file under the same clips. File › Link Media opens it any time; MCP `montage_relink`.
- **Project Manager** (File menu, MCP `montage_consolidate`; Premiere's Project Manager, Resolve's Media Management): copies the project to a new folder with the media it uses, for archiving or handing on. **Collect** copies each used file whole; **Consolidate** transcodes only the parts of each video the sequences use, plus handles, to ProRes 422 HQ or H.264, and points the clips (and transcripts, moved to the new timing) at the new files. Keep all sequences or just the active one and what it nests; media nothing uses is left out unless you keep it; missing files are reported.
- **Smart rendering** (Premiere's and Final Cut's): exporting to ProRes or DNxHR, frames that are one untouched clip of footage already in the same flavour, size, sampling and rate are copied from the source file rather than decoded and encoded again: faster, and exactly the original pictures. Anything that changes the picture (an effect, a move, a transition, another layer, a burn-in, a colour conversion, proxies) is rendered as usual. On by default; an Export dialog option.
- **Chapter markers** (Sequence › Add Chapter Marker, `Alt+M`, like Final Cut's and Premiere's): drawn as orange flags; an ordinary marker at the playhead becomes one. They are written as chapters into exported MP4, MOV and MKV files (players and YouTube read them; an option in the Export dialog). **Copy Chapters for YouTube** puts the list for a video description on the clipboard ("0:00 Intro", "1:05 Setup", timed from In when In and Out are set) and warns when YouTube would not show it: fewer than three chapters, or one under ten seconds.
- Constant speed changes and reverse, with optional ripple
- Snapshot undo/redo for every operation; drags and slider edits merge into one undo step
- **Render cache** (like Premiere's Render In to Out): Sequence › Render In to Out (Return) renders the frames between In and Out (or the whole sequence) as the Program monitor shows them, so heavy effects play in real time. A green render bar under the ruler shows what is rendered. Frames stay rendered until something that shows in them changes. Moving a clip keeps its frames, and undo brings them back. Sequence › Delete Render Files empties the cache. **Background Render** (Final Cut's; Sequence menu, off by default): after a few quiet seconds, the stretches with effects, titles or transitions render by themselves off the UI thread; editing or playing stops it until the next quiet spell.
- **Sequence Index** (a panel beside the Media bin, like Premiere's): every clip and marker in the sequence as a table, with its kind, colour label (a swatch and its name), audio role, track, start, end, duration, source In, media and effects. Type to filter on any column (a colour's name finds every marker and clip carrying it, as Premiere 26.2's marker search does), click a header to sort, double-click a row to select the clip and go to it, and rename a clip or marker in place (one undo step).
- **Workspaces** (Premiere's workspaces, Resolve's pages): the panels laid out for a task. **Editing**, **Colour** (scopes beside a large Program monitor, the Inspector full height), **Audio** (the mixer where the Source monitor was, wide meters), **Effects**, **Captions** and **Logging** (a wide bin with Find Shots, People and the Transcript) are a click away in the bar at the bottom right, in Window › Workspaces or on Alt+Shift+1 to 6. Arrange the panels as you like and Save as New Workspace to keep the layout under a name; Reset Workspace to Saved Layout puts it back. The current workspace is remembered, and `montage --workspace Colour` opens in one.
- **Keyboard Shortcuts** (Help › Keyboard Shortcuts, F1): every menu command can take any key, found by name or key. A key already in use moves only after asking. Keys can be reset one by one or all together, and layouts can be exported to or imported from a JSON file. Presets follow Premiere Pro (Montage's own), Final Cut Pro, DaVinci Resolve or Avid Media Composer.
- Scene-cut detection that cuts a clip at every shot change

**Effects and colour**
- Transform on every clip: position, scale, rotation, anchor, crop, opacity, flip, and fit/fill/stretch
- **Motion paths** (After Effects' and Premiere's): an animated position shows its path over the Program monitor, a dot a frame so their spacing shows the speed and a square at each keyframe; drag a square to move that keyframe (one undo step) while the box still moves the clip at the playhead.
- 13 blend modes
- Primary colour correction: lift, gamma and gain per channel, plus exposure, contrast, pivot, saturation, temperature, tint and offset
- One-click Auto Colour (grey-world balance and level stretch)
- **Match Colour** (shot matching, like Premiere's Color Match or Resolve's Shot Match): park on the look you want and choose Clip › Set Colour Reference, then select clips and choose Clip › Match Colour to Reference (Ctrl+Alt+Shift+C). Each clip gets a Color Correct whose per-channel lift, gain and gamma put its shadows, mid-tones and highlights on the reference's.
- **Colour groups** (Resolve's groups): select the shots of a scene, a camera or an interview and choose Clip › Colour Group › New Group from Selection. The Inspector then shows, for any member, the group's **pre-clip** grade, which runs on every member before its own effects (to match the shots), and its **post-clip** grade, which runs after them (the group's look); each clip keeps its own grade in between. Clips join and leave groups from the same menu, which also renames, deletes and selects a group's clips. MCP `montage_color_group`, and `montage_add_effect` with `group_stage`.
- Curves you drag in the Inspector (click to add a point, double-click to remove one), with presets, HSL/vibrance, `.cube` 3D/1D LUTs, black & white, invert
- **Export LUT from Grade** (Clip menu, MCP `montage_export_lut`; Resolve's Generate 3D LUT): the clip's colour effects at the playhead (Color Correct, Curves, Hue Curves, HSL, Levels, LUTs, colour space and OCIO transforms, black & white, Broadcast Safe) are baked into a 33-point `.cube` for on-set monitors, cameras and other applications. Effects a LUT cannot hold (blurs, masked grades) are left out and named.
- **Hue Curves** (like Lumetri's or Resolve's): Hue vs Hue, Hue vs Saturation, Hue vs Luma, Luma vs Saturation and Saturation vs Saturation, each drawn over its own scale; leave a stretch flat and those colours are untouched
- **Colour Warper** (Resolve's): a mesh over a hue and saturation wheel, twelve spokes by four rings round a grey centre that never moves. Drag a point to pull its colours to another hue and saturation, and those near it in proportion (the mesh shows where everything goes), for example to bring skin tones together or push a sky towards teal; select a point to brighten or darken its colours by stops; double-click to put one back. Preserve Luminance keeps moved colours at their brightness, Mix fades it, and it goes into exported LUTs. MCP `montage_add_effect` takes the mesh as text (`strings`, which also sets curves, hue curves and LUT files).
- **HDR Palette** (Resolve's HDR wheels): grading by zones of brightness measured in stops from mid grey, in the light the sequence shows, so it behaves the same in SDR and in HDR (PQ, HLG): Global plus Black, Dark, Shadow, Light, Highlight and Specular, each with its own colour wheel, exposure (stops), saturation, range and falloff (the dark zones reach every tone below their range, the bright ones every tone above it), and global contrast round a pivot, black offset and Mix. The tone curve can never turn over, it goes into exported LUTs, and grade versions and colour groups take it like any colour effect. The Inspector shows one zone at a time with its wheel. MCP `montage_add_effect` with `hdr_palette`.
- **Tone controls** on Color Correct, as in Lumetri's Basic Correction: Highlights, Shadows, Whites and Blacks each move their own part of the range and leave the far end alone, keeping each colour's hue as it gets lighter or darker; no combination can turn tones over. Vibrance lifts muted colours much more than already-saturated ones.
- **Colour wheels** for Lift, Gamma and Gain on Color Correct: drag a puck towards a hue to push the shadows, mid-tones or highlights that way; double-click to centre it
- **Compare with Reference** (Clip menu): the colour reference beside the current frame in the Program monitor, split by a divider you drag
- Chroma key with spill suppression, and luma key
- **Keyer** (green or blue screen, in the manner of Keylight and Premiere's Ultra Key): Clip › Key Out Green / Blue Screen reads the screen's colour from the picture and keys it. The matte comes from how far the screen's colour leads the other two (Screen Balance weighs them, Screen Gain sets how hard), which keeps hair and soft edges, then Clip Black and Clip White, Shrink / Grow, Soften, Despill with the lost brightness put back and Edge Desaturate tidy it; View shows the composite, the matte or a status view (clean black, clean white, grey where it is neither). MCP `montage_key_screen`.
- **Behind People** (the creator apps' "text behind subject"; Effects › Keying): put a title, shape or any clip behind the people in the shot beneath it, so a big headline sits behind someone's head. It uses the same MODNet matte as Remove Background, with Edge Shift, Soften and an Amount.
- **Track Matte Key** (as in Premiere): a clip shows only where another track's picture is, by its alpha or its brightness, or only where it is not (Reverse). The matte track is the one above unless you name another, and is hidden while it is used (or not, if you untick Hide the Matte). A title or shape over footage is the usual matte: text filled with video, or a moving reveal.
- Levels, Posterize, Glow, Film Grain (new each frame, strongest in the mid-tones), Directional Blur, Chromatic Aberration, Lens Distortion (barrel or pincushion), Letterbox (2.39, 2, 1.85, 4:3, 1:1, 9:16)
- **Super Scale** (like Resolve's Super Scale): Real-ESRGAN (BSD-3-Clause, 4.6 MB, downloaded the first time) enlarges footage and stills up to four times, redrawing edges and texture instead of blurring them. As a clip effect it works whenever the clip is shown larger than it was shot (scaled up, or SD or HD in a bigger sequence), and does nothing in smaller previews. Media bin › Create Super Scale Copy (2x, 3x, 4x) writes an enlarged copy beside the original (ProRes for video, with its sound; PNG for stills), as does `montage-cli upscale`. On a test picture shrunk to a quarter, it restores 4.3 dB more than plain scaling and as much edge detail as the original had. It is slow on a CPU (on four cores, about 1 s a frame from 480x270 and 4 s from 960x540, since the model always works at 4x), so render with Render In to Out or make a copy.
- **Generate Voiceover** (like Resolve's Speech Generator or CapCut's text to speech; Sequence menu, Ctrl+Alt+G): type a script and an AI voice speaks it onto an audio track at the playhead, or pick a caption track to have every cue spoken at its time (a little faster where a cue is too short for its words). Ten English voices, American and British, at 0.5x to 2x speed. It uses Kokoro-82M (Apache-2.0, 172 MB with its voices, downloaded the first time), about three times faster than real time on four CPU cores. Words become phonemes through misaki's pronunciation dictionaries (also Apache-2.0) and a C++ port of its rules for numbers, money, years, ordinals, abbreviations and word endings, so they come out as Kokoro expects; words the dictionaries lack are split into ones they know (voice + over) or sounded out. The files go in a Voiceover folder beside the project. `montage-cli speak "text" -o voice.wav` and MCP `montage_generate_speech` do the same.
- **Film Look** (like Resolve's Film Look Creator; Effects › Stylize): film's marks in one effect. Halation (the red-orange glow film's base throws round bright lights), bloom, grain that is strongest in the mid-tones and mostly shared across the colours as dye clouds are, gate weave (the frame's slow wander in the gate), softness, chromatic aberration, a vignette, flicker and lifted blacks. Gauge (65mm, 35mm, 16mm, Super 8) sets the grain's size and how far the frame wanders; each part has its own amount. Sizes are fractions of the frame, so previews and exports match, and a frame always renders the same.
- **Blemish Remover** (Refine; like Resolve 21's AI Blemish Remover): spots, pimples and small marks on each face (found every frame with YuNet) are healed from the skin round them. A mark must curve darker (or redder) in every direction at the scale of a spot, so creases, shadow edges and pores are left alone, and it must sit on skin away from the eyes, nostrils and hairline. Amount, sensitivity, the largest spot size, and Show Spots Found.
- **Redact Faces** (Privacy; Clip › Redact Faces…; Resolve and Premiere need a mask drawn and tracked by hand for each face, YouTube Studio's Blur Faces finds them): every face in the clip is found (YuNet), followed from frame to frame and grouped by person (SFace identities, checked every frame so someone stepping in where another person was starts a track of their own), then blurred, pixelated or covered with a solid colour in a soft ellipse or rectangle grown to take in the hair. A face the detector loses for a few frames (turned away, blurred by motion) stays covered: between two sightings its box moves from one to the other, and it is held for a set number of frames at either end of a track. The dialog shows each person found with a picture of them (named when People search knows them) to untick anyone who may be shown; the analysis is kept on the clip, so the choice can change at once, and outside the seconds analysed (a clip lengthened later) every face in the frame is covered. Strength, shape, expand, feather, hold, colour and Show Tracked Faces (red round the covered faces, green round those left showing) are in Effect Controls. MCP `montage_redact_faces` analyses, reports the people as numbered groups, and leaves people showing (`show`) or covers only some (`cover_only`) by number or name.
- **Focus Repair** (Blur & Sharpen; like Resolve 21's UltraSharpen, without a model): undoes a slight focus miss or lens softness by Richardson–Lucy deconvolution of the brightness with a Gaussian of the blur's size, accelerated, so detail the blur spread out is gathered back instead of edges merely exaggerated as Sharpen does. Colour follows the brightness, so no fringes; a noise threshold keeps grain from being sharpened.
- **Distort and stylize effects** (as in Premiere, Resolve and the creator apps):
  - Distort: **Wave Warp** (sine, triangle or square waves at any angle, moving if you give them a speed), **Twirl**, **Spherize** (bulge or pinch), **Ripple** (rings moving outwards), **Turbulent Displace** (fractal noise with complexity and evolution) and **Motion Tile** (smaller copies, offset, with mirrored edges).
  - From Premiere 26.2–26.3: **Magnify** (a circle or square of the picture enlarged in place, with feather, border and opacity), **Channel Blur** (red, green, blue and alpha blurred by their own amounts, in both directions or one) and **Noise** (brightness or colour noise, different each frame, kept within black and white or not).
  - Stylize: **Find Edges**, **Emboss**, **Halftone** (black dots, or CMY at the printer's angles), **Duotone**, **VHS** (soft tape picture, smeared and lagging colour, lifted blacks, scanlines, streaky noise, a tracking band and torn bottom lines) and **Stop Motion** (each frame held for a few).
  - **Motion Blur** (like Resolve's): on footage, each pixel is averaged along the path optical flow says it moves on while the shutter is open, set as a shutter angle (180° is film's usual; 360° doubles it).
  - **Deflicker** (like Resolve's, for timelapses and flickering lights): each of 16 × 9 areas of the frame (or the whole frame) is brought to its average brightness over the frames either side, so flicker goes and slow changes such as a sunset stay.
  - **Tilt-Shift Blur** (a miniature look: a sharp band, with a saturation boost) and **Camera Shake** (smooth random movement and rotation, zoomed just enough that the edges never show).
  - Sizes are in source pixels, so previews and exports match, and what moves is tied to the frame, so a frame always renders the same.
- **Object Removal** (like Resolve's Object Removal or After Effects' Content-Aware Fill): Effects › Refine › Object Removal paints out whatever its mask covers (a drawn shape, an object picked and tracked with an Object mask, or the People shape) and fills it with what plausibly lies behind, using LaMa (Apache-2.0, 208 MB, downloaded the first time). The area round the mask is worked on at 512 x 512, so small things like a logo, a sign or a passer-by keep their surroundings' detail; Grow Mask takes in their edges. Each frame is filled on its own, about 3 s a frame on four CPU cores, so render it, and expect some shimmer where the fill has to invent a lot on moving shots.
- **Face Refinement** (like Resolve Studio's): Effects › Refine › Face Refinement finds the faces in each frame (YuNet, the model People uses) and touches them up within a soft mask from their outline and landmarks, leaving the eyes and mouth out of it: Smooth Skin takes out small blemishes and texture on skin-coloured areas while keeping edges, and Brighten Eyes, Sharpen Eyes and Lighten Face do as they say. Show Face Mask shows where it works. It follows faces as they move, since they are found again every frame.
- **Remove Background** (like CapCut's Remove Background, or Resolve's Magic Mask on a person): Effects › Keying › Remove Background cuts the people out of a shot without a green screen, so the tracks below show around them (or keeps the background and removes them). Hair and soft edges are kept; Edge Shift grows or shrinks the cut and Soften feathers it. Any video effect can also be limited to the people in the picture with the mask's **People** shape (invert it to grade or blur everything but them). It uses MODNet (Apache-2.0, 26 MB, downloaded the first time), a portrait model: it finds people, not objects (pick those with an Object mask). About 0.8 s a frame on four CPU cores.
- **Depth** (like Resolve's Depth Map): Depth Anything V2 Small (Apache-2.0, 99 MB, downloaded the first time) works out how near each part of the picture is, from the picture alone. Three effects use it, under Effects › Depth: **Lens Blur (Depth)** keeps one distance sharp and blurs what is nearer or farther (focus, in-focus range, falloff, blur size); **Depth Fog** thickens a colour with distance; **Depth Map** shows the depth as grey, for checking it or as a matte; **Relight** (like Resolve's Relight) adds a virtual light after the shoot: surfaces turned towards it brighten in its colour and those turned away fall into shadow, while surfaces facing the camera keep their light. Their directions come from the depth's slopes, and its direction, height, intensity, shadows, relief and reach (how far back it lights) can be set. Any video effect can also be limited to a range of distances with the mask's **Depth Qualifier** (from far to near, with softness), so a grade can touch only the background or only the subject. The depth is worked out once per frame from the clip's source picture (about a second a frame on four CPU cores), so render with Render In to Out for real-time playback.
- **Video Noise Reduction** (like Resolve's temporal and spatial NR): up to three frames either side are warped onto the frame along the optical flow and averaged where they match it, so moving pictures are cleaned without ghosting; then an edge-preserving pass on luma and chroma takes out what is left, more where the temporal pass could not help. The noise level is measured from each frame, or set by hand. It runs on the source frames before the clip's other effects, and works under a mask (for example only the sky or a face). On a test clip, temporal and spatial together cut the noise by 12 dB, and edges keep 98 % of their contrast. It is heavy: use Render In to Out for real-time playback.
- Corner Pin: four keyframeable corners map the picture onto any quadrilateral, for screen replacements. The corners show in the Program monitor to drag onto the surface.
- Masks on every video effect:
  - An ellipse or rectangle with feather, expansion, rotation, opacity and invert, all keyframeable. Drag it in the Program monitor to move it, pull its handles to resize it, or turn it with the handle above it (Shift for 15° steps).
  - **Bézier masks** (like Premiere's free-draw Bézier, Resolve's curve window or Final Cut's Draw Mask): choose the Bézier shape and click in the Program monitor to place corners, dragging to pull out curves; click the first point to close the path. Then drag points and handles (Alt breaks a handle pair), click the outline to add a point, Alt-click a point to make it a corner or smooth, Ctrl/Cmd-click to remove it, and drag inside to move the whole path. The edge is anti-aliased, and feathered and expanded by true distance. **Animate Path** keys the whole path at the playhead, so a rotoscoped shape is redrawn frame by frame and shown as one Mask Path row in the keyframe panel. The path lives in the mask's box, so tracking the mask carries it. MCP `montage_add_effect` takes `mask_path`.
  - A **Gradient** (like Resolve's linear window or a graduated filter): the effect fades out across the mask's box, full above it and none below; turn it to grade the sky, one side of the frame or the floor.
  - An HSL qualifier selects by hue, saturation and luma with softness, for example to grade only skin or only the sky. Show Mask displays the selection.
  - **Object masks** (AI): choose the Object shape and click a person or thing in the Program monitor.
    - Alt-click marks what is not part of it, a drag draws a box around it, and Ctrl/Cmd-click removes a click.
    - ◀ Track / Track ▶ follow it through the clip, finding it again after it turns or is briefly hidden.
    - Feather, expansion, invert and Show Mask work as for the shapes, and the mask stays with the footage through trims and speed changes.
    - It runs locally with EdgeTAM, Meta's on-device model in the Segment Anything 2 family (Apache-2.0), on ONNX Runtime. The 65 MB model is downloaded on first use.
- **Auto Reframe** (like Premiere's Auto Reframe or Resolve's Smart Reframe): Sequence › Auto Reframe Sequence… makes a copy of the cut at 9:16, 1:1, 4:5 or 16:9 where every clip fills the frame and follows its subject, found from what moves against the camera and what stands out. Motion can be slower (interviews), default or faster (sport). Clip › Auto Reframe does the same for selected clips, and Sequence › Duplicate Sequence copies a sequence as it is.
- **Export Versions** (Premiere's Auto Reframe with Media Encoder, CapCut's and Descript's multi-format export): File › Export Versions… delivers the cut in several shapes in one step: 16:9 for YouTube, 9:16 for Shorts, Reels and TikTok, 4:5 for feeds and 1:1. Each shape that is not the cut's own becomes a reframed copy kept in the project ("<name> 9x16", replaced when made again), its captions raised clear of the platforms' buttons when tall, and every version is queued to render into one folder as H.264, HEVC or ProRes, captions burned in and the sound at -14 or -16 LUFS. MCP `montage_export_versions` renders them and returns the files.
- **Digital Cinema Package (DCP)** (DaVinci Resolve Studio's DCP export; Premiere, Final Cut and Avid need DCP-o-matic or easyDCP): File › Export DCP… makes the SMPTE DCP a cinema server plays and a festival asks for. The picture is 2K JPEG 2000 in the DCI profile (OpenJPEG's cinema mode, under 250 Mbit/s) in Flat (1998 x 1080), Scope (2048 x 858) or the full container, the sequence fitted inside on black and turned into DCI X'Y'Z' from its colour space (HDR tone mapped into the cinema's range); the sound is the mix at 48 kHz, 24 bits, in 5.1 (7.1 DS from a 7.1 sequence; stereo on left and right) with multichannel labels. Montage writes the MXF track files itself, matching the reference implementation (CineCert's asdcplib reads them back bit for bit), and the composition playlist with the SMPTE Bv2.1 metadata, packing list with SHA-1 hashes, asset map and volume index, in a folder named by the Digital Cinema Naming Convention (title, kind, aspect, language, territory, audio, studio, date, facility). Frames are encoded several at a time; 23.976 and 29.97 sequences play at 24 and 30. When it is done the package is checked as a server would (files, sizes, hashes, assets and durations, picture format, frame counts and bit rate, sound); an independent DCP checker (Ymagis's ClairMeta) passes Montage's packages on all 78 of its checks. MCP `montage_export_dcp` and `montage_verify_dcp` (which checks any DCP folder).
- **IMF masters** (Interoperable Master Format, as Netflix, Amazon, Disney+, Apple and broadcasters ask for; DaVinci Resolve Studio and Avid export it, Premiere and Final Cut need a third-party tool): File › Export IMF Master… makes an Application #2E package (SMPTE ST 2067-21:2021). The picture is the sequence's size or HD, UHD or 4K (fitted on black), as full-range RGB 4:4:4 of 10 or 12 bits in Rec.709, P3-D65 PQ, Rec.2020 PQ (with mastering display metadata) or Rec.2020 HLG, coded with OpenJPEG in the JPEG 2000 IMF profiles: lossless (the reversible profiles, as studios ask) or capped at 200 to 800 Mbit/s, main and sub levels chosen from the picture rate and bit rate, several frames at once. The sound is the mix at 48 kHz, 24 bits, in stereo, 5.1 or 7.1 DS with ST 2067-2 channel labels. Montage writes the AS-02 track files itself (the layout CineCert's asdcplib writes), a composition playlist whose essence descriptor list repeats each file's descriptors, a packing list with SHA-1 hashes and an asset map. 23.976, 24, 25, 29.97, 30, 50, 59.94 and 60 fps (29.97 and 59.94 masters are padded with black and silence to a multiple of five frames, so the sound fills whole frames), and 120 above HD. Netflix's Photon (the reference IMF checker) passes the packages with no errors or warnings, SDR and HDR, lossless and lossy; each is also checked when done (files, hashes, resources and descriptors, profile, frame and sample counts). MCP `montage_export_imf` and `montage_verify_imf`.
- **Review without a service** (Frame.io in Premiere, Blackmagic Cloud review in Resolve, offline): File › Export for Review… queues an H.264 review copy (1080p, 720p or full size; timecode, an optional watermark and the captions burned in; all of the cut or In to Out) and writes a single HTML page beside it that plays it in any browser, offline, with nothing fetched from anywhere. Reviewers step frame by frame (arrow keys, J/K/L) or scrub, mark a range with I and O, type a note under their name and save the notes as a file; the page keeps them between visits, shows the editor's markers and message, and merges other reviewers' files. File › Import Review Notes… (or Import Markers) turns each note into a marker at its frame, named and coloured by reviewer, resolved ones ticked. MCP `montage_export_review`; `montage_import_markers` takes notes files.
- Speed ramps and slow motion:
  - **Time Remapping** gives every clip a keyframeable speed curve (linear, hold or eased) inside its length. Picture and linked sound follow it together.
  - **Speed ramp presets** (CapCut's speed curves; Clip › Speed Ramp, MCP `montage_speed_ramp`): Montage, Hero, Bullet, Jump Cut, Flash In, Flash Out, and easing into or out of slow motion. Each shapes the Time Remapping curve with eased keys, scaled so the clip still plays the same footage in the same length (so it never runs out of media and the cut does not move); linked sound follows, the keys stay editable, and Remove Ramp puts it back to an even pace. Set Frame Sampling to Optical Flow or AI Frames for smooth slow parts.
  - **Frame Sampling** sets how in-between frames are made in slow motion: Nearest Frame, Frame Blending, Optical Flow, which moves pixels along their motion instead of cross-fading, or **AI Frames (RIFE)** (like Resolve's Speed Warp), which draws them with RIFE 4.26 (MIT). RIFE's weights are its authors' own release, downloaded the first time (23 MB) and unpacked beside its network. On a moving photo it lands a third as far from the true in-between frame as Optical Flow and a fiftieth as far as blending. It takes about 3 s a 1080p frame on four CPU cores, so render with Render In to Out; until the model is downloaded it falls back to Optical Flow.
- Tracking and stabilisation (built in; no OpenCV):
  - **Stabilize** effect: analyses the clip's camera movement when added, then smooths it (or locks the shot). It can correct position, scale and rotation, and zooms to keep the edges hidden. Smoothness can be changed at any time without analysing again.
  - **Rolling Shutter Repair** (Premiere's, Final Cut's): pans and shakes on phones, mirrorless cameras and drones lean verticals and wobble, because the sensor reads its rows one after another. The effect measures the camera's movement (as Stabilize does) and moves each row back to where the picture was mid-frame, from the speed around that frame and the readout (the share of a frame the sensor takes: about 30–60 % for phones, more for many mirrorless cameras in 4K). Zoom to Fill hides the moved edges. Stabilize has the same correction as its Rolling Shutter setting, and MCP `montage_add_effect` measures the movement when either is added. On a synthetic pan sheared as a full-frame readout would shear it, the repaired picture is within 40 % of the difference the shear made.
  - **Mask tracking**: ◀ Track / Track ▶ in any mask section follows what the mask covers from the playhead to the clip's start or end. It tracks position, scale and rotation, and writes keyframes.
  - **Planar tracking** (screen replacement, like Mocha or Resolve's planar tracker): put a picture on the track above a phone, monitor or sign, add Corner Pin, drag its corners onto the surface, and press ◀ Track / Track ▶. The corners follow the surface in perspective and are keyed on every frame. A blank screen is held by its bezel.
  - **Follow** (like Final Cut's object tracker): Transform › Follow ▶ moves a title, graphic or blurred clip with what is under its Position in the footage beneath it, keying position (and scale and rotation if chosen). Anchor offsets it from the point it follows.
  - Under the hood: pyramidal Lucas–Kanade on Shi–Tomasi corners with forward–backward checks, RANSAC similarity fits, and RANSAC homographies fitted against the first frame, so planar tracks do not drift.
- Gaussian blur, sharpen, vignette, mosaic, mirror, drop shadow
- **Adjustment layers** (Clip › New Adjustment Layer, or Generators in the Effects panel): the effects, opacity, transform and blend mode on the layer apply to everything on the tracks below it, for a grade or a look over many clips at once.
- Keyframes on every parameter: linear, hold or smooth, with previous/next navigation
- **Effect presets** (Premiere's effect presets, Resolve's PowerGrades): Clip › Save Effects as Preset keeps the selected clip's effects, with their settings and keyframes, under a name. Presets are listed first in the Effects panel: double-click to add one to the selected clips of its kind, or drag it onto a clip. Right-click to delete one, import a `.montagepreset` file, or open the folder they are kept in, to share them.
- **Several clips at once in the Inspector** (Resolve 21's): with more than one clip selected, a value changed in the Inspector (a transform, a colour wheel, any effect's parameter) goes to the same parameter on every selected clip of that kind, each at its own playhead position, in one undo step; a note at the top says how many clips it reaches. Effects are matched by type and place among those of their type.
- **Keyframes panel** (like the timeline in Premiere's Effect Controls): every animated parameter of the selected clip as a row of keys over the clip's length.
  - Click or drag a box to select keys, and drag them to retime (rows move together, without passing other keys).
  - Arrow keys nudge (Shift for 10 frames) and Delete removes. Right-click for Linear, Hold, Smooth or **Bezier**, or to **Ease In**, **Ease Out** or **Easy Ease**. Double-click adds a key.
  - **After Last Keyframe** (After Effects' loopOut, Resolve 21's keyframe loop and ping pong): from the right-click menu, an animation can hold, **Loop**, **Ping-Pong** back and forth, or **Loop and Offset** (each cycle carries on from the last, for a steady spin or climb), saved with the project.
  - **Copy and paste keyframes** (After Effects', Premiere's, Resolve's): select keys and press `Ctrl+C` in the panel (or right-click › Copy), then select a clip, put the playhead where the animation should start and press `Ctrl+V` (or Paste at Playhead). The keys keep their spacing, values, interpolation and handles; they go into the same parameters, an effect's into that effect or the clip's first effect of the same type, and replace any keys at the same frames. One undo step, and the pasted keys are selected.
  - A click on the ruler or an empty lane moves the playhead.
  - **Graph** shows the values as curves, like After Effects' value graph. Drag keys in time and value, and drag a Bezier key's handles to shape the curve; the two handles stay in line unless Alt is held. Click a parameter's name to see its curve alone, with its values. Bezier keys get automatic handles until one is dragged: smooth through each key, and flat where the curve turns and at the ends.
- Volume and opacity lines on timeline clips (Sequence › Show Clip Volume / Show Clip Opacity):
  - Drag a line to raise or lower it. Ctrl/Cmd-click adds a keyframe; drag keyframes in time and value (Shift for value only).
  - Alt-click a keyframe to delete it, or right-click it for Linear, Hold or Smooth.
  - Volume is drawn on a perceptual scale up to +6 dB.
- Titles (font, outline, shadow, background box, alignment, tracking), colour mattes, gradients, SMPTE bars
- **Shape layers** (Effects › Generators › Shape): a rectangle (with rounded corners), ellipse, polygon, star, line or arrow, filled with a colour or a linear or radial gradient, with a stroke that can be dashed. Every value is keyframeable, and Trim Start, Trim End and Trim Offset (as in After Effects) draw the outline on or send a segment round it.
- **Interlaced footage** (1080i and 480i/576i broadcast, DV, HDV, older camcorders) is deinterlaced automatically, as in Premiere and Resolve: each frame flagged as interlaced keeps its first field, and a line of the other field is rebuilt from the lines either side only where it combs, so still detail keeps its full height and motion loses its teeth.
- **Camera RAW stills** (as Resolve 21's Photo page takes them): Canon CR2/CR3, Nikon NEF, Sony ARW, Fujifilm RAF, Panasonic RW2, Olympus ORF, Pentax PEF, Hasselblad, Phase One, Adobe DNG and the other formats LibRaw reads import like any still. Each is developed once with the camera's white balance and turned upright, into 16-bit Rec.709, and the camera's name goes in the media's Camera field. **RAW settings** in Interpret Footage (Resolve's Camera Raw panel, Premiere's Source Settings; MCP `raw_exposure`, `raw_temperature`, `raw_tint`, `raw_highlights`, `raw_half`): exposure in stops (−5 to +5, brightened highlights rolling off), white balance as shot or by the light's colour temperature (presets for tungsten, fluorescent, daylight, cloudy and shade, or 2000–25000 K) and tint, highlight recovery (clip, blend or rebuild) and a half-size decode for fast editing, developed at the camera's own exposure with no automatic brightening. **CinemaDNG**: a folder of numbered DNG frames (Blackmagic, DJI, Sigma fp, Kinefinity, ML RAW) imports as one video clip at the run's frame rate, each frame developed as it is shown, with the same RAW settings.
- **Lottie animations and SVG graphics** import like footage. Lottie `.json` files exported from After Effects with Bodymovin or downloaded from LottieFiles play as clips with transparency, at their own frame rate and length, expressions included. SVGs are stills. Both are drawn by ThorVG at the size they are shown, so they stay sharp when scaled up.
- **Animated titles and templates**: titles animate in and out (fade, slide in four directions, pop, typewriter, wipe), sit at a placement that stays inside the title-safe area at any frame size (lower left, lower centre, upper right...), can style the lines after the first in their own size and colour, and can carry an accent bar. Ready-made designs are listed under Titles in the Effects panel: Lower Third, Lower Third (Box), Centred Title, Chapter Heading, Call-out, Typewriter, End Card, Rolling Credits and News Crawl.
- **Rolling credits and crawls** (Roll / Crawl on any title, like Premiere's Roll and Crawl and Resolve's Scroll): the whole title moves up the frame, or along it to the left or right, over the clip's length at a steady speed, starting and ending off screen or where it is laid out (credits taller than the frame finish with their last line inside the title-safe area), with optional easing at each end. MCP `montage_add_title` takes `motion` and the `credits` and `crawl` templates.
- Transitions: cross dissolve, dip to black/white, wipe, luma wipe (dark or bright parts first), clock wipe, **Shape Wipe** (like Premiere's Shape Dissolve: circles, diamonds, squares, stars, hearts or crosses growing over the picture, one or a grid of them, turned to any angle), push, slide, iris, cross zoom, **3D Cube** and **3D Flip** (the two shots on faces of a turning cube, or the sides of a card, in perspective); for creators, **Whip Pan**, **Zoom Blur** and **Spin** (smeared along their motion), **Glitch** (bands thrown sideways, colours split) and **Light Leak** (a warm light sweeping across); and **Smooth Cut** (like Premiere's Morph Cut or Resolve's Smooth Cut), which hides a jump cut in an interview by morphing the outgoing frame into the incoming one along their optical flow
- Scopes: waveform, RGB parade, vectorscope (with the skin-tone line and 75 % targets), histogram, or **All Four** at once in a 2 × 2 grid (Resolve's quad view)
- Colour management and HDR:
  - Media spaces come from the file's tags, and Interpret Colour overrides them: Rec.709, sRGB, Rec.2020, Display P3, Rec.2100 PQ and HLG, Sony S-Log3 (S-Gamut3 and S-Gamut3.Cine), ARRI LogC3 and LogC4, Panasonic V-Log, Canon Log 3, Apple Log (iPhone), DJI D-Log, Fujifilm F-Log2, Nikon N-Log, RED Log3G10, Blackmagic Film Gen 5, DaVinci Intermediate / Wide Gamut, ACEScct. The new curves and gamuts match the colour-science library to 2e-6.
  - Each sequence works in Rec.709, Rec.2020, P3, PQ or HLG. Clips are converted into it, with tone mapping between HDR and SDR and a display rendering for log footage.
  - HDR sequences are previewed tone mapped to SDR.
  - HDR exports are 10-bit and tagged, and PQ files carry HDR10 metadata: MP4 and MOV files the MaxCLL and MaxFALL measured from what was rendered, encoders that state them up front (x265, Matroska) the levels from Sequence › Analyse HDR Light Levels…, which also warns when highlights pass the mastering peak. An HDR master can also be delivered as a tone-mapped SDR version.
  - The scopes measure HDR and wide-gamut sequences as delivered, not their SDR preview; for PQ and HLG the waveform, parade and histogram are scaled and labelled in nits (reference white and the mastering peak marked, a 10 000 to 1 000-nit top for PQ) and the frame's peak and average light are read out.
  - Colour Space Transform effect: convert one clip between any two of these spaces.
  - OpenColorIO Transform effect (when built with OpenColorIO 2.1+):
    - Applies a studio's `.ocio` config, `$OCIO`, or a config built into OCIO (e.g. `ocio://studio-config-latest`).
    - Converts colour space to colour space, or to a display/view with an optional look; it can also run inverted.
    - The Inspector lists the config's spaces, displays, views and looks.
    - ACES 2.0 output transforms come with OCIO 2.5's built-in configs.

  - click an angle or press 1–9 to switch;
  - while the program plays, each switch is a cut at the playhead, so a scene can be cut live;
  - Shift cuts while stopped;
  - audio can follow the video.

  - the speaker labels of one transcribed recording of everyone (choose the angle that shows each person).

**Audio**
- Clip gain and pan, both keyframeable
- **Auto Mix** (Sequence menu, like Resolve's AI Audio Assistant): every audio clip is listened to and recognised as dialogue, music or effects (from transcripts where there are any, otherwise the pauses and syllable rhythm of speech and the steady beat of music); each can be corrected. Applying brings each kind to its level (presets for web and streaming, podcasts, or broadcast), evens out dialogue within each clip with volume keyframes (up to 6 dB either way), and dips the music under speech, all in one undo step as ordinary clip volume.
- **Match Voice** (Clip › Set Voice Reference, then Match Voice to Reference; like Resolve's Dialogue Matcher): makes dialogue from another microphone or room sound like a reference clip. Both voices' long-term spectra are measured over their speech, and a Parametric EQ (low shelf, three bells, high shelf) fitted to the difference goes first on each clip, where it can be adjusted. Matching again replaces it.
- **Beat and bar markers** (Clip › Add Bar Markers / Add Beat Markers, like Final Cut's beat detection): the music clip's tempo and beats are found by listening to it (no model), and markers land on every bar ("Bar 12") or beat ("12.3") where the clip plays them, for cutting picture on the beat with snapping.
- **Fit Music to Length** (Clip menu, like Premiere's Remix or Resolve's music editor): shortens or lengthens a music clip to In–Out, the picture, or any length, by skipping or repeating whole bars where the music matches itself best (harmony and timbre, a bar either side of each join). The start and the ending stay as they are, joins get short crossfades on the beat, and each piece starts a fraction of a frame in as needed so the beat runs on. The result is within half a bar of the length asked for.
- **Add B-Roll by What Is Said** (Clip menu, or MCP `montage_auto_broll`; like Descript's and CapCut's AI B-roll): the cut's dialogue is split into sentences, each compared with what the footage shows (CLIP), and over the best-matching sentences (half of them by default) a few seconds of the best-matching shot go on V2, picture only, so the voice carries on. It chooses from the videos selected in the bin, or every video the sequence does not use; footage is indexed first if needed.
- **Make Highlights** (Clip › Make Highlights…, or MCP `montage_highlights`; like the highlight edits Resolve 21.1's assistant builds): the liveliest moments of long footage, from the videos selected in the bin (or all of them), in a new sequence of the length you ask for. Each half second is scored by how much louder it is than the clip usually is, how much moves in the picture and, if you describe what to look for, how much it looks like that (CLIP). Moments play in the order they happened, a few seconds each, with cuts moved off words.
- **Cut to the Beat** (Clip › Cut Selected Media to the Beat, or MCP `montage_cut_to_beat`; like CapCut's beat sync): select a music clip on the timeline and some clips in the bin, and they are laid back to back with a cut on every bar (or every few beats or bars over MCP), from the music's first bar to its end. Each piece is the middle of its clip, stills fill any length, a video too short for its piece is passed over, and the pictures come without their sound.
- **Bleep words** (Transcript panel › Bleep): select words and bleep them, or bleep every swear word found in the cut. A tone (1 kHz at -12 dB by default, or silence) covers each word with 5 ms ramps, and the word is masked in the captions ("f***"). The stretches are kept on each clip in source time, so trims and moves keep the bleep on the word. MCP `montage_bleep` also takes a phrase or time ranges.
- **Checkerboard Dialogue by Speaker** (Clip menu, or MCP `montage_checkerboard`): a clip where several people speak is split where the speaker changes, in the silence between them, and each person's parts go to an audio track of their own (a free track below, or a new one named after them), so each voice can be levelled and cleaned up separately before the mix. It uses the transcript's speaker labels. Keyframes move with each part, and it is one undo step.
- **Auto Duck Music** (Clip menu): select music clips, tick the dialogue tracks, and the music dips under speech, fading down before it and back up after it. Speech is found from transcripts' words, or from loudness. The result is volume keyframes you can adjust on the clip's line.
- Track faders, pan, mute and solo in a mixer panel. **Clear Solo** (Sequence menu, Resolve 21.1) clears every solo at once and, used again, brings the same solos back.
- **Fader automation** (Premiere's Audio Track Mixer, Pro Tools, Fairlight): each track strip has a mode. **Read** plays the track's volume and pan lanes and the faders follow them; **Write** records the fader and pan from play to stop (then hands over to Touch); **Latch** records from the first move to stop; **Touch** records while you hold a control and glides back over a second when you let go; **Off** ignores the lanes. Each pass is one undo step, thinned to the points it needs; while stopped, moving a fader on a track reading its lane sets the lane at the playhead. The mix, exports and stems all hear it (MCP `montage_automate_track`). **Sequence › Show Track Automation** draws each audio track's volume lane across its row, labelled with its mode: drag the line or a point, Ctrl/Cmd-click to add a point, Alt-click to delete one; with no points the line is the fader's level.
- **Surround (5.1 and 7.1)**: choose the sequence's audio channels in Sequence Settings, and each mixer strip gets a surround panner in place of its pan dial. Drag the sound among the speakers (towards the middle spreads it over all of them), scroll to narrow a stereo track to a point, and right-click for its width, an LFE send, Front, or the Centre speaker for dialogue. Tracks routed to a bus are placed by the bus. You hear the mix folded down to stereo (ITU-R BS.775); exports carry every channel (5.1 or 7.1 WAV, AAC, ProRes...) unless you pick the stereo fold-down, and loudness normalisation weights the surrounds as BS.1770 says.
- **Immersive audio and ADM masters** (Dolby Atmos-style; Resolve's Fairlight and Pro Tools have it, Premiere and Final Cut do not): 5.1.2, 5.1.4, 7.1.2 (the Atmos bed, its pair overhead at the sides) and 7.1.4 layouts at ITU-R BS.2051's speaker positions. Each panner gets a height (Alt+wheel or right-click), panned between the ear-level and overhead rings at constant power, and a track can be made an **audio object** (right-click; drawn as a diamond). A position can **move**: Animate Position keys it at the playhead (dragging then keys it wherever the playhead is), and in Write, Latch or Touch the panner is recorded as it plays, like the faders; the mix glides between positions without clicks, and a moving object goes into the ADM master as timed blocks. The mix is heard folded down to stereo (overhead speakers into their side at -3 dB), exports carry every channel (FFmpeg's 5.1.2 to 7.1.4 layouts) in PCM, while AAC, FLAC and Opus (8 channels at most) fold the heights into 7.1 or 5.1, as the export summary says, and IMF and DCP masters fold the heights into 5.1 or 7.1. **File › Export Immersive Master (ADM BWF)** writes the interchange file Atmos and the EBU ADM renderer read: a BW64 wave with chna and axml (BS.2076-2) chunks, the bed of every non-object track named by the BS.2094 common definitions, and each object (a track going straight to the speakers, not through a bus) as a channel of its own at its panner's position (azimuth, elevation, distance), its LFE send kept in the bed, 48 kHz 24-bit; solo and mute count as when playing. EBU's reference renderer (ear) reads and renders the masters. MCP `montage_set_surround` (height, object, the new layouts) and `montage_export_adm`.
- **AAF for audio post** (File › Export AAF for Audio Post, `montage-cli aaf`, or MCP): the audio tracks as an AAF composition for Pro Tools, Fairlight, Nuendo or Media Composer. It links to mono 24-bit 48 kHz WAVs (one per channel of each source, in a "<name> Media" folder beside it). Clip positions and source offsets are exact, with whole sources so the mixer has every handle. Crossfades become AAF transitions, fades become fade lengths, and clip gain and its keyframes become Audio Gain operations. Clips that change speed or play backwards, and nested sequences, are rendered to their own files first. The file is checked by an independent AAF reader (pyaaf2) and a strict compound-file reader (olefile).
- **Stems** (Export › Stems, or `--stems tracks|buses|roles`): beside the export, a 24-bit WAV of each audio track, of each bus plus "Main" for the tracks going straight to the master, or of each audio role ("No Role" for untagged clips). Each is its part of the mix exactly as it plays there, so together they add up to the mix.
- **Audio roles** (Final Cut's roles, Premiere's clip types; Clip › Audio Role): tag audio clips Dialogue (`Ctrl+Alt+1`), Music (`Ctrl+Alt+2`), Effects (`Ctrl+Alt+3`) or a role of your own, whichever tracks they sit on; selecting a video clip tags its linked sound. **Detect Roles by Listening** tags untagged clips (or the selection) with what Auto Mix's classifier hears, and Auto Mix itself records what it mixed each clip as and keeps a role you gave by hand. Track effects keep running past the last clip, so reverb and echo tails ring out.

- Render and Replace bakes a clip's effects into a new file to save CPU, and Restore Unrendered brings the original back (both on the clip's right-click menu). - Effects:
  - EQ: 3-band and 5-band parametric EQ (low shelf, three bells, high shelf), high/low-pass.
  - Dynamics: compressor, limiter, de-esser (split-band), noise gate (threshold, range, attack, hold, release), and a three-band **multiband compressor** (Linkwitz-Riley splits that add back up flat; each band's threshold, ratio and gain, with a soft knee).

- Dialogue cleanup (Effects › Audio Filters › Restoration):
  - **Noise Reduction** learns the noise print from the quietest moments of the recording itself, then turns down hum, hiss and room tone by up to the amount you set.
  - **Voice Isolation** uses RNNoise, a neural network from Xiph, to keep speech and remove everything else, mixed with the original by Amount.
  - **Enhance Speech** (like Premiere's Enhance Speech or Descript's Studio Sound) uses DeepFilterNet3 (MIT or Apache-2.0, 16 MB, downloaded the first time it is added) to take noise and room out of a voice: in the test it brings the pauses in a noisy recording down by 48 dB, against 14 dB for Noise Reduction. Max Reduction caps how far anything is turned down, for a lighter touch. Keep › Everything but Speech does the opposite and gives the music, effects and ambience with the voice about 8–10 dB down, for a music-and-effects bed.
  - **De-Click** takes out clicks, crackle and scratches. Each is found where the sound departs from what the samples before and after it predict, and only those samples are rebuilt, from the sound either side (least-squares interpolation). In the test, clicks and short scratches on music and on speech come down 40 dB or more while everything else is left exactly as it was.
  - **De-Hum** notches out 50 or 60 Hz mains hum and up to 16 of its harmonics, each a couple of hertz wide, so the voice round them is untouched.
  - **De-Reverb** (like iZotope RX De-reverb or Premiere's Reduce Reverb) takes the room out of a recording. The late reverberation is estimated from the sound itself, as what was heard 50 ms earlier dying away at the room's rate, and subtracted; the room's reverberation time is measured from how fast the sound falls after it stops (or set by hand). In the test, speech in a simulated 0.8 s room has its reverberation time found within 3 % and its late reverberation brought down by 2.6 dB relative to the voice, while dry speech passes nearly untouched.
  - **Spectral Repair** (Audition's Spectral Frequency Display and healing, iZotope RX's Spectral Repair; Clip › Spectral Repair…): the clip's sound as a spectrogram (time across, frequency up on a log scale, level as colour). Drag a box around a sound that shares its moment with the dialogue but not its frequencies (a phone, a squeak, a whistle, a siren), let **Find Frequencies** fit the box to what stands out there, then **Heal** it (each frequency brought down to the level heard just before and after, never raised, the original phase kept) or **Attenuate** it by up to 96 dB; tick All frequencies for a cough or a bump. Everything outside the box is left as it was, the edges are feathered so nothing clicks, each repair is an undo step and the picture shows the result. Repairs are kept on the clip in source time, so trims keep them on the sound, and they run before the clip's other restoration. MCP `montage_spectral_repair` takes boxes in timeline seconds, finds the band itself when none is given, or only reports what stands out (`find_only`).
  - Noise Reduction, Voice Isolation, Enhance Speech, De-Click and Pitch Shift process the clip's whole source audio in the background and cache the result. Playback uses the original audio until the cleaned copy is ready (usually a few seconds); exports always wait for it.
- **Room tone** (iZotope RX's Ambience Match, the dialogue editor's fill): right-click a gap on an audio track › Fill Gap with Room Tone. The background of the clip before the gap (or after it) is learned from its quiet moments between words, and new sound with the same spectrum, stereo width and level fills the gap, written as a WAV in a Room Tone folder beside the project, so the room never drops out under a cut. MCP `montage_fill_room_tone`.
- Crossfades: equal power or constant gain
- Loudness normalisation to -14, -16, -23 or -24 LUFS (ITU-R BS.1770 / EBU R128 gated measurement)
- **Live loudness meter** under the audio meters while playing: momentary (400 ms), short-term (3 s) and integrated LUFS, loudness range (LU) and true peak (dBTP). The integrated value turns green on the chosen target (EBU R128 -23, ATSC A/85 -24, streaming -14, Apple and podcasts -16), amber within 2 LU, and red otherwise; true peak turns red above -1 dBTP. Reset starts a new measurement.
- **Quality Check** (Sequence › Quality Check…, like the QC pass broadcasters run in Baton or Vidchecker, and the Harding test): the sequence or In to Out is checked before delivery for flashing that can trigger photosensitive seizures (ITU-R BT.1702, Ofcom and WCAG 2.3.1: more than three flashes a second over a quarter of the screen, or to and from saturated red), picture levels outside EBU R103, black and frozen picture, silence, clipping, integrated loudness and true peak against a delivery target (streaming, podcast, EBU R128, ATSC A/85), and spelling in captions and titles. Each problem is listed with its timecodes; double-click one to go there, or add red "QC:" markers spanning them all.
- **Broadcast Safe** effect (Color; Premiere's Video Limiter, Final Cut's Broadcast Safe): limits a clip or an adjustment layer to EBU R103 (-5 to 105 %) or strictly 0 to 100 %, pulling over-range colours towards their own luma so hue is kept, with a soft knee; Highlight Unsafe Areas stripes what it would change.

Captions are checked in their track's language and titles in the dictionary chosen under Edit › Spelling (English, US or UK, from SCOWL's word lists, built in; UK English takes both -ise and -ize). Acronyms, numbers and web and mail addresses are left alone. A ⚠ in the Captions panel and Quality Check's Spelling check list the captions and titles with mistakes; MCP `montage_spell_check` checks, learns and forgets words.
  - **Translate Track** (Captions › More): a copy of the track in another language, with the same timings, translated on this computer. Opus-MT models (University of Helsinki, CC-BY-4.0) cover English to and from 18 to 22 languages. A pair without its own model goes through English. Each model is about 270 MB and downloads the first time that pair is used. Also `montage-cli translate subs.srt --to de`.
  - **Dub into English** (Captions › More, or MCP `montage_dub`; like YouTube's and ElevenLabs' AI dubbing, done on this computer): a caption track in any language Opus-MT covers is translated into English, each cue is spoken at its time with an AI voice (Kokoro, a little faster where a cue is short) on a new "Dub (English)" audio track, and the original audio is lowered (18 dB by default) while the dub speaks, as in a voice-over translation. The English captions are kept as a hidden track.
  - The CC button shows captions in the Program monitor. When exporting, captions can be burned into the picture, embedded as a subtitle track (mov_text in MP4/MOV, SubRip in MKV, WebVTT in WebM, with the track's language), or both.
- Interchange both ways with Premiere Pro, DaVinci Resolve, Final Cut Pro, Avid and Nuke:
  - Final Cut Pro 7 XML, FCPXML, OpenTimelineIO and CMX 3600 EDL.
  - Imported timelines find their media (missing files come in offline) and keep links, dissolves, speed changes, titles and markers.
- Project files are readable JSON (`.montage`) and relink moved media through relative paths
- Crash safety:
  - Unsaved work is saved to a recovery copy about a second after each edit. After a crash or forced quit, the next launch offers to recover it.
  - If audio plugins were in use, it offers to start in safe mode with plugins disabled.
  - Every five minutes of editing, a timestamped snapshot is kept, the newest 20 per project (File › Open Auto-Save Snapshot).
- `montage-cli` for headless rendering and automation

## Building

Ubuntu 24.04 or Debian with Qt ≥ 6.4 and FFmpeg ≥ 6:

```bash
./scripts/setup-deps.sh                 # installs compilers, Qt 6, FFmpeg dev packages
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
./build/src/app/montage                 # the editor
./build/src/montage-cli --help          # the command-line tool
```

Optional libraries are used when found: OpenColorIO (OCIO transforms), lilv (LV2 plugins) and ONNX Runtime (object masks). `setup-deps.sh` installs all three; ONNX Runtime goes to `/opt/onnxruntime` from Microsoft's release archive (point `ONNXRUNTIME_ROOT` at another copy).

On macOS: `brew install qtbase qtmultimedia ffmpeg opencolorio lilv libraw openjpeg onnxruntime ninja pkgconf`, configure with `-DCMAKE_PREFIX_PATH="$(brew --prefix)"`, then `scripts/package-macos.sh build` makes the DMG. On Windows, build in an MSYS2 UCRT64 shell with the `qt6-base`, `qt6-multimedia`, `qt6-tools`, `ffmpeg`, `opencolorio`, `lilv`, `libraw`, `openjpeg2` and `onnxruntime` packages; `scripts/package-windows.sh build` makes the portable folder and zip, and `packaging/windows/montage.iss` (Inno Setup) the installer.

CMake options:
- `-DMONTAGE_BUILD_APP=OFF` builds only the engine and CLI, without Qt Widgets or Multimedia.
- `-DMONTAGE_BUILD_TESTS=OFF` skips the tests.
- `-DMONTAGE_REQUIRE_ONNXRUNTIME=ON` stops the configure step if ONNX Runtime is missing (release builds use it).
- `-DMONTAGE_WITH_LIBRAW=OFF` leaves out camera RAW stills (LibRaw 0.20+, LGPL-2.1 or CDDL-1.0, linked as a shared library when installed).
- `-DMONTAGE_WITH_THORVG=OFF` leaves out Lottie and SVG import (ThorVG 1.1.2, MIT, is fetched and compiled at configure time).

The object mask, speaker and visual search tests need their models: `scripts/fetch-models.sh ~/montage-models`, then set `MONTAGE_OBJECT_MODEL=~/montage-models/edgetam-video`, `MONTAGE_SPEAKER_MODEL=~/montage-models/speakers` and `MONTAGE_VISUAL_MODEL=~/montage-models/clip-vit-b32`; the people tests `MONTAGE_FACE_MODEL=~/montage-models/faces`, the depth tests `MONTAGE_DEPTH_MODEL=~/montage-models/depth`, the slow-motion tests `MONTAGE_RIFE_MODEL=~/montage-models/rife`, the background removal tests `MONTAGE_MATTE_MODEL=~/montage-models/matte`, the speech tests `MONTAGE_TTS_MODEL=~/montage-models/tts`, the object removal tests `MONTAGE_INPAINT_MODEL=~/montage-models/inpaint` (the app reads the same variables). The speech tests read `MONTAGE_TEST_WHISPER_MODEL`.

## Using the editor

1. **Import** with `Ctrl+I`, or drag files or folders onto the Media panel or the timeline.
2. **Pick shots.** Double-click a clip to load it in the Source monitor, mark `I` and `O`, then press `,` to insert or `.` to overwrite at the playhead on the targeted tracks. The track buttons in the header set the target.
3. **Cut** with the timeline tools. Drag clip edges to trim, use `B` for ripple trim, `N` to roll an edit point, and `Y`/`U` to slip or slide. `Ctrl+K` adds an edit at the playhead.
4. **Add effects** from the Effects panel. Drag them onto clips, or select a clip and double-click the effect. Tune every parameter in the Inspector; the ◷ button animates a parameter with keyframes.
5. **Mix** in the Audio Mixer, and check levels on the meters and colour on the Scopes.
6. **Export** with `Ctrl+M`.

The first clip placed in an empty sequence sets the sequence's frame size and rate.

## AI agents (MCP)

`montage-cli mcp` is a [Model Context Protocol](https://modelcontextprotocol.io) server, so Claude and other MCP clients can edit with Montage. It works over stdio and speaks both the 2026-07-28 revision and the earlier initialize handshake (2024-11-05 to 2025-11-25).

Its tools work on `.montage` files by path. Each edit is saved at once, and the previous version is kept beside the project as `.bak` for `montage_undo`. The tools can:
- probe media, create projects and list a project's timeline;
- place media, split, remove (with ripple), move, trim and change the speed of clips;
- add titles, effects (including masked ones), transitions and markers (chapter markers too), and list the chapters for YouTube;
- run a delivery quality check (flashing, levels, black, freeze, silence, clipping, loudness) and mark the problems;
- automate a track's fader and pan (mode and points);
- export and import marker lists (CSV, Avid locators, Resolve EDL);
- copy a project with its media to a new folder, whole or consolidated to the parts used;
- list offline media and relink it, by searching a folder or file by file (Replace Footage too);
- hold alternative takes on a clip (auditions), try them in place and keep one;
- transcribe (with speaker labels), translate caption tracks, dub them into English, find spoken phrases in the cut, cut by transcript (phrases, filler words, retakes, long pauses, optionally with Smooth Cuts), and build a cut from a script;
- find shots by description, and find, name and join the people in the footage;
- generate voiceovers from text or from a caption track;
- log media (ratings, labels, keywords, metadata fields, bins), interpret footage (frame rate, pixel aspect, alpha, fields), make subclips, auto-tag shots, and find media by text or smart-bin rules, optionally saving the rules as a smart bin;
- add shape layers (drawn on if asked), and write Super Scale copies of videos and stills;
- make a first mix (roles, levels, dialogue rides, ducking), set up a 5.1 or 7.1 mix and place tracks in it, match voices to a reference, mark a music clip's bars or beats and fit music to a length, duck music under dialogue, match clips' colour to a shot, add adjustment layers, and make a reframed copy of the cut at another aspect ratio;
- return a rendered frame as an image so the agent can check its work;
- render with any preset, with progress, optionally folding surround down to stereo and writing stems;
- export and import EDL, OTIO, FCP 7 XML and FCPXML, and export AAF for audio post.

```bash
claude mcp add montage -- montage-cli mcp      # Claude Code
```
Other clients take the same command in their MCP settings, e.g. `{"mcpServers": {"montage": {"command": "/Applications/Montage.app/Contents/MacOS/montage-cli", "args": ["mcp"]}}}`. Reopen a project in the app to see changes an agent made.

**Agent link: agents on the open project** (as Premiere 26's AI Assistant, Avid's agentic editing and Descript's Underlord work on the project in front of the editor). Turn on Tools › Let AI Agents Edit This Project, then connect with `montage-cli mcp --live` (Tools › Agent Link… shows the exact command and copies it):

```bash
claude mcp add montage-live -- montage-cli mcp --live
```

Every tool then works on the project open in Montage when its `project` is left out: each change appears at once and is one undo step named "Assistant: …" (Edit › Undo takes it back, and so does the agent's `montage_undo`, which leaves the editor's own changes alone). `montage_live_context` tells the agent what is open: the sequence, playhead, In and Out and the selected clips (ids for other tools), and moves the playhead or selects clips to show a result. Tools run off the UI thread on a copy saved beside the project, one at a time; if the editor changes the project while one runs, its result is not applied and the agent is told to try again. The link is MCP over HTTP on 127.0.0.1 only, with a key the app writes (readable by the user only) to `mcp-live.json` in Montage's configuration folder; HTTP clients can use it directly (`claude mcp add --transport http montage-live http://127.0.0.1:PORT/mcp --header "Authorization: Bearer KEY"`). Requests from web pages on other sites are refused.

**Assistant panel** (Window › Assistant; like Premiere 26's AI Assistant): ask for an edit in your own words ("remove the ums from the interview", "put a lower third for Jane Doe, Director, at 10 seconds", "make a 30-second cut for social") and a language model does it with the same tools on the open project, each change one undo step "Assistant: …". The panel lists each tool as it runs and what it reported, and Stop drops a request mid-way. Montage brings no model: Settings choose Claude through Anthropic's API (the key, or `ANTHROPIC_API_KEY`; Claude also sees frames the tools render) or any OpenAI-compatible chat endpoint (OpenAI, or a local Ollama, LM Studio or llama.cpp server, so nothing leaves the computer), and the model. Requests go only to the endpoint chosen.

## Architecture

```
src/core     Project model (value types), keyframes, effect catalogue, edit operations,
             snapshot undo, timecode, JSON project I/O.  No GUI dependencies.
src/media    FFmpeg probing, frame-accurate video decoding, audio decoding and peaks,
             decoder pool and LRU frame cache, scene detection, proxy generation.
src/render   CPU compositor (float RGBA, multi-threaded), effects and transitions,
             title rendering, stateful audio mixer, FFmpeg exporter.
src/app      Qt Widgets application: editor state, playback controller (render thread +
             audio sink), timeline, monitors, inspector, media bin, effects browser,
             scopes, mixer, meters, dialogs.
src/cli      montage-cli.
tests        Qt Test suites: core, render, media, and offscreen GUI integration tests.
```

Notes on the design:
- **Edits** are pure functions over a value-type `Project` (`core/EditOps.h`). Undo stores snapshots, so every edit is undoable without per-command inverse code. Interactive drags re-apply the operation to the state captured when the drag began, so the result depends only on how far the pointer has moved.
- **Rendering** uses 32-bit float, premultiplied RGBA throughout. Filters run in clip space before the fixed transform, as in Premiere. Decodes happen at the size the clip occupies on screen, which keeps preview cheap.
- **Playback** renders the newest requested frame on a worker thread and drops late frames. Paused frames always render at full quality.
