# DaVinci Resolve (Cut/Edit/Fusion/Color/Fairlight/Photo + Studio) and Avid Media Composer: 2026 feature inventory (as of 7 Oct 2026)

Scope note: current shipping versions are **DaVinci Resolve 21.1.1** (1 Oct 2026) and **Avid Media Composer 2026.8** (available 1 Sept 2026). Items marked [OLDER] were introduced before 2024 and are included for context; [DEPRECATED]/[REMOVED] are flagged where found. "Studio" means DaVinci Resolve Studio ($295 perpetual). Several primary pages (avid.com resource centre, avid.com press room, BusinessWire) returned HTTP 403 to the fetch tool, so some Avid detail comes from trade press and resellers rather than Avid's own pages.

## What are the headline features of the latest Resolve and Media Composer releases up to October 2026?

### Takeaway
Resolve 21 (final 2 Jun 2026) added a whole new Photo page plus a large AI wave (IntelliSearch, Speech Generator, CineFocus, face age/reshape/blemish tools, Slate ID, UltraSharpen, Motion Deblur), and 21.1 (9 Sep 2026) added a Studio-only MCP server so external AI assistants (Claude, Claude Code, ChatGPT Codex) can drive Resolve, while moving Python scripting to Studio. Media Composer 2026.8 is a smaller, workflow-focused release: PhraseFindAI Multicam Auto Cut, a "Ready to Edit" agentic prep feature, transcript versioning, Content Core integration, an uncapped free tier, and a controversial re-tiering of Shared Projects (third-party storage now Enterprise-only).

## Which AI features exist in each product, when were they introduced, are they paid-only, what hardware do they need, and how widely are they used?

### Takeaway
Resolve's DaVinci Neural Engine dates to Resolve 16 (2019) and now spans dozens of tools; the large majority of the visual AI tools (Magic Mask, Speed Warp, Super Scale, Smart Reframe, IntelliTrack, Object Removal, Face tools, MCP) are Studio-only, and AI work officially needs 16 GB VRAM (Win/Linux) or 16 GB RAM (Mac). Avid's AI is concentrated on dialogue: PhraseFind AI / ScriptSync AI (2023.8), the Transcript Tool (2024.6), transcript editing/sharing (2025.12), and Multicam Auto Cut + Ready to Edit (2026.8), with Gemini-based search previewed.

## What does Resolve's colour pipeline offer (node grading, colour management, ACES/OCIO, HDR, windows, tracking, qualifiers, scopes)?

Resolve's Color page remains the industry reference: 32-bit float YRGB node grading, DaVinci Wide Gamut/RCM, ACES 1.3 and ACES 2.0 (with OCIO 2.4.2 since Resolve 20), Dolby Vision/HDR10+/HDR Vivid (Studio), power windows, AI tracking, qualifiers and HDR scopes; 2024–2026 additions were ColorSlice, Film Look Creator, Chroma Warp, MultiMaster Trim Manager, per-format HDR trims, layer-list node view and group grade versions.
